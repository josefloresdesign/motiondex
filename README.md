# Motiondex

Every free web and app animation in one place. Watch it move, copy the code, ship it.

**Live site:** https://josefloresdesign.github.io/motiondex/

- **Catalog:** animations from Tailwind CSS, Animate.css, Magic UI, Motion, GSAP, LottieFiles, Rive, Reanimated, flutter_animate, SwiftUI, Jetpack Compose and more, with code for several stacks.
- **Originals (Beta):** animations made for Motiondex, free under MIT.
- **Psychology:** research and UX laws that explain why good motion works.

Built with [Space DS](https://github.com/josefloresdesign/space-ds). A single static `index.html`, no build step.

## Ownership

Motiondex is an index. Each third-party animation belongs to its author and keeps its own license, linked on every animation. If you made one and want it removed or the credit fixed, reach out on [LinkedIn](https://www.linkedin.com/in/josefloresdesign/).
